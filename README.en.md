# Music Collection

[简体中文](README.md) · [English](README.en.md)

Personal music collection archive, deduplicated and indexed by genre, with in-browser preview and streaming capabilities.

## Features

- **Categorized Archive**: Browse tracks categorized into Pop, International, Instrumental, and Soundtracks.
- **Embedded Audio Player**: Streamlined playback bar with volume, repeat modes, and audio streaming via proxy.
- **1-Click Bilingual Toggle**: Switch interface language between Simplified Chinese and English via desktop topbar circle button or mobile drawer settings (`[L]` keyboard shortcut).
- **Responsive Mobile UX**: Mobile slide-out drawer, dedicated category modal, 40px+ touch targets, and dark mode.

## Development

Static site files are located in `docs/`. Run with any local HTTP server:

```powershell
python -m http.server -d docs 8080
```
